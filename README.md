# QuickX — React + Vite

Одностраничный сайт в тёмной технологичной палитре (белый / красный / графитовый).

## Запуск в VS Code

Требуется Node.js 20.19+ или совместимая версия 22+.

```bash
npm install
npm run dev
```

Откройте адрес `http://localhost:5173/`.

## Создание сборки

```bash
npm run build
```

Готовые файлы будут в каталоге `dist/`.

## GitHub + Cloudflare Pages

1. Загрузите файлы проекта в репозиторий GitHub (папку `node_modules` загружать не нужно).
2. В Cloudflare Pages подключите нужный репозиторий и ветку.
3. Framework preset: **Vite**.
4. Build command: `npm run build`.
5. Build output directory: `dist`.
6. После сохранения настроек Cloudflare Pages будет публиковать новые коммиты.

## Где что находится

- `src/App.jsx` — все секции, навигация, иллюстрации и FAQ.
- `src/styles.css` — внешний вид, адаптив, эффекты, анимации.
- `src/config.js` — единая ссылка для всех кнопок связи с менеджером.
- `public/assets/logo.png` — утверждённый логотип QuickX (прозрачный PNG).
- `public/favicon.svg` — иконка вкладки.
- `index.html` — метатеги, заголовок страницы.

## Примечания

- Кнопки используют **указанный владельцем сайта внешний URL**, а не прямой адрес `t.me`. Перед публикацией убедитесь, что он действительно ведёт к правильному менеджеру.
- Биржевой график является **декоративной иллюстрацией**, не отображает актуальные котировки и не является торговым терминалом.
- Точки на карте иллюстрируют международную географию; это **не список офисов**. Наличие офиса нужно уточнить у менеджера.
- FAQ и формулировки о доступности услуг следует согласовать с фактическими условиями работы сервиса и требованиями законодательства.
